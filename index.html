  • 07:30-08:00

    地点：酒店附近 推荐本地肠粉 / 粿条汤

    地点：长山尾灯塔 / 青澳湾 / 北回归线广场 南澳畅行预约必做，不预约可能无法上岛
  • 18:00-20:30

    晚餐 + 回市区酒店

    地点：青澳湾海鲜排档 / 酒店附近

待办清单

  • 确认酒店区域与入住时间，具体到地址和联系电话；待定时保留字段，后续替换。
  • 在“南澳畅行”小程序提前预约南澳岛入岛，确认预约成功并保留截图；这是本次最关键的提前准备。
  • 确认中海黄金海岸周末是否开放水上乐园、营业时间及电话 0754-88762688，避免白跑。
  • 确认租车取车/还车地点、车行电话、是否需要提前预订；留出返程加油和停车时间。
  • 核对是否存在节假日票务售罄风险：海鲜大排档、热门景点、网红打卡点等提前同意路线分流。

实用贴士

  • 南澳岛属于较强节奏路线，周六早出发更稳；如天气不好，优先保留南澳岛与海边拍照时间，减少中海景点等待。
  • 10月下旬日落约 17:40，青澳湾看日落最适合；若拍照需要留出 15-20 分钟提前占位。
  • 无论是否买门票，都建议提前电话确认：中海黄金海岸相关活动是否开放、是否需预约，避免在景区门口踩空。
  • 在一切公开页面里，绝不写确认号、证件号、房间号；仅保留景点/地址/电话和时间安排。
  • 如果有地点路线导航需求，可直接点击页面中的导航按钮，系统会尝试调用高德地图或打开地图搜索页。
